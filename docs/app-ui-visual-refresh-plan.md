# CCGUI App UI Visual Refresh Plan

## 目标

本次只重新定义 `app 级 UI`，不动已经完成的：

- `message` 展示主题
- `chat input` 输入区样式

本次覆盖范围：

- Welcome 页面
- Workspace 左侧 sidebar / session list
- 设置页 / 项目配置 / 会话配置等属性页
- 文件树、文件预览、终端等外围面板

核心目标：

- 保留 CCGUI 现有 `深色 + 橙色强调` 的识别度
- 去掉现在偏“纯后台 / 纯工具页”的平铺感
- 增加一点科技感、时尚感、层次感
- 让消息区之外的界面和新的消息主题不打架

## 对当前界面的判断

当前 `message / input` 已经开始形成自己的风格，但 app 其他区域还停留在较旧的视觉语言里：

- 背景层次太单一，很多区域都是 `#1E1E1E / #27272A / #3F3F46`
- 卡片、侧栏、对话框、设置页大面积使用同一种面板语言，记忆点不够
- Welcome 页和 Workspace 页之间的气质割裂，缺少统一的“产品级外壳”
- 橙色虽然存在，但多数时候只是 `按钮色 / 选中色`，还没有形成完整的品牌气氛
- 某些区域的灰色边框过多，导致 UI 显得重、旧、闷

结论：

不是要推翻深色橙色，而是要把它升级成：

- 更有层次的深色底
- 更克制但更高级的橙色高光
- 更轻的面板边界
- 更明确的页面分区和主次关系

## 新的整体方向

### 风格关键词

- `Midnight Workbench`
- `Warm Tech`
- `Graphite + Ember`

### 气质定位

不是拟物，不是霓虹，也不是 IDE 纯复刻。

应该是一种：

- 深色工作台
- 带一点暖金属感
- 带一点产品展示感
- 比传统后台更精致，比花哨科技风更克制

换句话说：

- 基底仍然是深色工作流 UI
- 但面板、欢迎页、侧栏要有“被设计过”的感觉
- 不是一堆灰框拼起来

## 视觉原则

### 1. 背景不再是单块纯平

整个 app 外壳应该至少有三层背景：

- 全局底色：偏石墨黑，不是纯黑
- 主工作区：略亮一层
- 面板表面：再亮一层，带轻微暖灰

并允许局部使用很轻的氛围渐变：

- 左上偏冷灰
- 右下偏暖橙棕

目的不是“看出渐变”，而是让纯深色界面不那么死。

### 2. 边框减重，靠层次区分区域

当前很多区域太依赖 `1px 灰边框`。

新方向：

- 大区块优先用 `背景层次 + 阴影 + 内描边`
- 少用一圈硬边框把所有东西框出来
- 边框只留在需要明确交互边界的地方
  - 输入
  - 下拉
  - 选中态
  - 分割面板

### 3. 橙色只做“热区”和“品牌热量”

橙色不应该铺太多。

它应该集中出现在：

- 当前选中项
- 主按钮
- 关键 hover
- 品牌高光
- welcome 页主视觉细节

而不是：

- 到处都有橙边框
- 所有 badge 都偏橙
- 每个 panel 都有橙色描边

### 4. 页面之间要统一壳体语言

Welcome、Settings、Workspace 不能像三套系统。

统一方式：

- 同一套背景层级
- 同一套 panel 表面语言
- 同一套高光和 hover 逻辑
- 同一套分割线和滚动区域处理

## 新的颜色系统

以下不是最终代码常量名，而是设计目标。

### 背景层

- `app-bg`: `#121316`
- `app-bg-elevated`: `#17191D`
- `panel-bg`: `#1B1E23`
- `panel-bg-soft`: `#20242A`
- `panel-hover`: `#262B33`
- `panel-active`: `#2D3440`

判断：

- 比旧版更偏蓝灰石墨
- 仍然足够稳，不会偏紫
- 能更好承接橙色高光

### 文字层

- `text-primary`: `#ECEDE8`
- `text-secondary`: `#B3B8C3`
- `text-muted`: `#7C8594`
- `text-dim`: `#5B6270`

文字不再偏米黄，也不偏冷白，避免和暖橙冲突。

### 强调层

- `accent-primary`: `#F97316`
- `accent-hover`: `#FB923C`
- `accent-soft`: `rgba(249, 115, 22, 0.14)`
- `accent-glow`: `rgba(249, 115, 22, 0.22)`

辅助强调色只做少量搭配：

- `accent-cool`: `#38BDF8`
- `accent-violet-soft`: `#8B5CF6`

注意：

冷色只做陪衬，不抢主品牌。

### 边界层

- `border-subtle`: `rgba(255, 255, 255, 0.05)`
- `border-default`: `rgba(255, 255, 255, 0.08)`
- `border-strong`: `rgba(255, 255, 255, 0.12)`
- `border-accent`: `rgba(249, 115, 22, 0.38)`

## 组件表面语言

### A. 主面板

用于：

- settings 右侧内容区
- welcome 主卡区
- project/session 配置面板
- file preview / terminal / sidebar 内卡片

建议样式：

- 背景：`panel-bg`
- 内描边：`border-subtle`
- 圆角：`14px`
- 阴影：`0 10px 30px rgba(0,0,0,0.22)`
- 局部顶部高光：非常轻的纵向渐变

### B. 次级卡片

用于：

- project card
- setting item
- session row hover 容器
- 空状态卡片

建议样式：

- 背景：`panel-bg-soft`
- hover：轻微提亮 + 轻微上浮
- 选中：橙色内发光，不用粗外框

当前 Welcome 页 `project card` 已确定一版更轻的实现标准：

- 不使用重玻璃或强高斯模糊
- 不使用实心深灰卡片
- 采用 `弱透明白表面 + 轻白边框` 的方式，让背景氛围光可以透进来
- 默认背景建议控制在 `rgba(255, 255, 255, 0.024)` 左右
- hover 背景建议控制在 `rgba(255, 255, 255, 0.05)` 左右
- 默认边框建议控制在 `rgba(255, 255, 255, 0.13)` 左右
- hover 边框建议控制在 `rgba(255, 255, 255, 0.18)` 左右

判断原则：

- 卡片应该是“轻表面”，不是“自己有很重颜色的块”
- 边框要比旧版 `#3F3F46` 更轻、更亮
- 如果追求“更细”，优先调低边框存在感，而不是盲目用 `0.5px`
- 如果视觉上发暗，优先略提亮边框，而不是继续加深卡片底色

### C. 交互控件

按钮 / 下拉 / 分段选择器：

- 平时偏哑光
- hover 时提亮背景
- active / selected 用橙色热区
- focus 用细橙描边，不要大面积橙填充

## 各页面建议

### 1. Welcome 页

Welcome 页应该最像“产品首页”，而不是一个大表单。

建议：

- 页面背景加入轻微大面积氛围渐变
- Logo 区和标题区更有中心感
- Project card 改成更精致的 `工作台卡片`
- “新建项目”卡不再只是虚线思路，而是更明确的主入口卡
- 搜索框做成更高一级的主控件

当前已验证的 Welcome `project card` 方向：

- 卡面保持轻透明，不做强玻璃实验
- 卡面颜色不超过很弱的白色透明层
- 主要依赖页面背景氛围与边框形成层次
- hover 只做轻微提亮和轻微上浮
- `missing` 卡片沿用同一套结构，只在边框上加红色提示，不单独做一张重红卡

重点提升：

- 顶部标题区
- project card 的层次和 hover
- 分类标题与折叠逻辑的视觉质量

### 2. Session Sidebar

Sidebar 不该只是“窄灰条”。

建议：

- sidebar 背景与主工作区形成轻微明度差
- session item 改成更轻的胶囊/卡片行
- 当前 session 用暖橙内高光，不要只靠块状背景
- 顶部项目区、底部工具区做清晰分层
- 文件树区域要和 session list 有明确分区

要避免：

- 整条 sidebar 全是同一种灰块
- active 行像默认列表选中态

### 3. Settings / 属性页

Settings 现在更像管理后台。

建议：

- 左侧导航改成更轻、更产品化的 section rail
- 右侧内容区做成连续 surface，而不是大量重复的平面模块
- 每个 section 的标题、说明、控件之间要建立稳定节奏
- setting item 减少生硬边框，更多依靠间距和层次

项目配置 / 会话配置也沿用这一套：

- 对话框表面与 settings 主面板同语言
- 顶部标题区更简洁
- radio group / select / config block 统一控件风格

### 4. 文件树 / 文件预览 / 终端外围

这些区域不能抢消息区，但要比现在更完整。

建议：

- 文件树背景更偏工具面板
- 预览区更偏内容面板
- 终端外壳更偏设备面板

三者统一：

- 相同圆角体系
- 相近边界语言
- 不同的明度级别

## 不动的区域

为了避免这次改造失控，以下保持现状：

- 聊天消息排版
- message 主题开关系统
- 输入框区域
- 已完成的 thinking / tool use / status 样式逻辑

新的 app UI 只负责给这些区域提供更好的“壳”。

## 实施策略

### 第一阶段：Token 和外壳

先统一：

- app 背景
- panel 背景
- 边框 / 阴影 / hover 规则
- 主按钮 / 次按钮 / 输入 / 下拉

优先文件：

- `Workspace.vue`
- `SettingsDialog.vue`
- `Welcome.vue`
- `SessionSidebar.vue`

### 第二阶段：页面级重构

按页面细化：

- Welcome
- Settings
- Sidebar
- FilePreview / FileTree / Terminal 外层

### 第三阶段：细部润色

- 空状态
- badge
- 分段选择器
- 滚动条
- 分隔线
- hover / active 动效

## 推荐的最终调性

如果只用一句话概括：

> 保留 `深色 + 橙色` 的 CCGUI 基因，但把外围 UI 从“灰色工具界面”升级成“有暖科技感的工作台产品界面”。

这次不是换品牌色，而是升级：

- 深色层次
- 面板气质
- 页面结构感
- 产品完成度
